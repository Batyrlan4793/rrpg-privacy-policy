Политика конфиденциальности Kakeibo

Последнее обновление: 29 сентября 2026 г.

Kakeibo — приложение SelfRPG Studio для личного учета доходов, расходов, сбережений и бюджета. Для работы приложения не требуется учетная запись.

1. Какие данные использует приложение

Пользователь может вводить суммы доходов и расходов, категории, планы, комментарии, итоги месяца и другие данные личного бюджета. К расходу можно по желанию прикрепить фотографию, сделанную камерой, либо выбрать изображение из галереи.

2. Где хранятся данные

Финансовые записи, настройки и история Kakeibo хранятся локально в памяти приложения на устройстве. Фотографии, сделанные через Kakeibo, сохраняются в закрытом хранилище приложения. Для фотографий, выбранных из галереи, приложение хранит ссылку доступа к выбранному пользователем файлу.

3. Сбор, использование и передача

Kakeibo не отправляет данные личного бюджета разработчику, не продает их и не передает рекламным компаниям. В приложении нет рекламы и собственной серверной учетной записи. Данные используются на устройстве для ведения бюджета, расчета показателей, отображения истории и аналитики.

При экспорте месяца в PDF пользователь сам выбирает приложение или получателя, которому будет передан созданный файл. После передачи применяются правила конфиденциальности выбранного пользователем сервиса или приложения.

4. Камера и фотографии

Kakeibo обращается к камере или выбранному изображению только после действия пользователя. При выборе фотографии из галереи приложение получает доступ только к выбранному пользователем файлу, а не ко всей медиатеке.

5. Системное резервное копирование

Android может включать данные приложения в системное резервное копирование и восстановление, если такая функция включена пользователем на устройстве. Это функция операционной системы и учетной записи пользователя, а не сервер Kakeibo.

6. Безопасность

Данные приложения хранятся в закрытом хранилище Android, доступ к которому ограничен приложением и средствами операционной системы. Kakeibo не использует собственный сервер для хранения финансовых записей пользователя.

7. Срок хранения и удаление

Данные сохраняются, пока пользователь не удалит соответствующие записи в приложении, не очистит данные Kakeibo в настройках Android или не удалит приложение. Локальные фотографии расходов, созданные Kakeibo, удаляются вместе с удаляемой историей месяца, когда это предусмотрено функцией приложения. Фотографии, выбранные из галереи, остаются под управлением пользователя.

8. Дети

Kakeibo не предназначено специально для детей и не создает учетные записи пользователей. Приложение не отправляет разработчику персональные или финансовые данные пользователей.
