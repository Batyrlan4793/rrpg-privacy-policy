# Privacy Policy for RRPG

Last updated: January 2026

RRPG ("the App") is a mobile application available on Google Play.  
This Privacy Policy explains how we collect, use, and protect user data.

---

## Information We Collect

We may collect the following types of data:

### 1. Authentication Data
- Email address (used for account registration, login, and password recovery)

Authentication is handled securely via **Firebase Authentication**.

### 2. App Usage & Crash Data
- Anonymous crash reports
- Performance and diagnostics data

This data is collected using **Firebase Crashlytics** to improve app stability and performance.

### 3. User-Generated Content
- In-app progress and data created by the user

All such data is stored securely using **Firebase** services.

---

## How We Use Your Information

We use collected data to:
- Provide and maintain core app functionality
- Authenticate users
- Send account-related emails (registration, password reset)
- Monitor app stability and fix bugs
- Improve user experience

---

## Data Sharing

We do **not** sell, trade, or share personal data with third parties, except:
- When required to operate core services (Firebase)
- When required by law

---

## Data Security

We take reasonable measures to protect your data using industry-standard security practices provided by Firebase.

---

## Children's Privacy

RRPG is **not intended for children under the age of 13**.  
We do not knowingly collect personal data from children.
